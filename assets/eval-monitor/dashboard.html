  1. 在浏览器打开 StreamLake 的评测任务列表页面。
  2. 按 F12 打开开发者工具，进入 Network / 网络，刷新页面。

  4. 将从 GET ... HTTP/1.1 开始、包含 Cookie 和 Referer 的整段内容粘贴到下方。服务会自动提取并保存 Cookie 与 project ID。
