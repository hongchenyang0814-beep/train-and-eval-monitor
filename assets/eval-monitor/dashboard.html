StreamLake 平台连接

正在读取配置状态
  1. 在浏览器打开 StreamLake 的评测任务列表页面。
  2. 按 F12 打开开发者工具，进入 Network / 网络，刷新页面。
  3. 找到名称含 GetIamProjectList 的请求，右键选择复制请求标头，或打开 Headers 后复制完整请求头。
  4. 将从 GET ... HTTP/1.1 开始、包含 Cookie 和 Referer 的整段内容粘贴到下方。服务会自动提取并保存 Cookie 与 project ID。

绑定训练任务

选择训练 Monitor 已发现的任务。日期和任务名称会同时显示；说明文档是可选的，没有文档也可以绑定。评测页只读取该任务目录中的 run_manifest.json 和 training_task.md，不会复制训练日志。
